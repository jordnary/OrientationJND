# Gabor 光栅方位差辨别实验

本项目保存已完成的序列呈现相同／不同判断实验、分析代码和实验报告。实验于 2026 年 9 月 23 日完成，4 位参与者均为裸眼或矫正视力正常，以 P001–P004 匿名编号。正式实验采用 16 英寸、16∶10 笔记本屏幕，实际全屏分辨率 2560 × 1600 像素，环境照明相同且良好。

## 主要结果

共获得 576 个正式试次，答对 475 次，总正确率为 **82.47%**。相同试次正确率为 **96.88%**，虚报率为 **3.13%**，无超时。练习 64 次和演示主试次 96 次不进入正式统计。

| 方位差 | 不同试次正确数 | 不同正确率 | 平衡正确率 |
| --- | --- | --- | --- |
| 0.5° | 8／48 | 16.67% | 56.77% |
| 1° | 16／48 | 33.33% | 65.10% |
| 2° | 31／48 | 64.58% | 80.73% |
| 4° | 46／48 | 95.83% | 96.35% |
| 8° | 47／48 | 97.92% | 97.40% |
| 16° | 48／48 | 100.00% | 98.44% |

平衡正确率为不同试次正确率与合并相同试次正确率的均值，各档共享相同控制基线。实验后的统一单调回归与线性插值给出 P001–P004 的探索性 75% 阈值分别为 2.000°、1.833°、1.389°和 0.833°。这些结果描述本任务下的行为表现，不作为群体 JND 或两选一任务的感觉阈限。

## 实验设计

每位参与者完成 144 个正式试次，其中相同与不同各 72 次。非零方位差为 0.5°、1°、2°、4°、8°和 16°，每档 12 个不同试次，正负方向各半；所有试次混合随机排列。参考方位为 0°，两次光栅相位独立随机化。F 表示相同，J 表示不同。

计划时序为注视 0.5 s、参考刺激 0.5 s、间隔 1 s、比较刺激 0.5 s、作答窗口最多 5 s、试次间隔 0.3 s。反应时从第二刺激消失、作答提示出现时计算。每次正式会话另有 8 个反馈练习，正式阶段每 24 次安排休息。

Gabor 尺寸为窗口高度的 0.3，空间频率参数为每个刺激宽度内 7.2 个周期，对比度参数为 0.8。观看距离未测量，刺激未进行视角校准；height 单位与 cycles per stimulus 不能写成视角度数和 cycles/degree。

## 复现分析

在项目目录中运行，分析无需启动 PsychoPy 窗口：

```powershell
python -m pip install -r requirements-analysis.txt
python summarize_study.py
python build_report.py
python -m unittest discover -s tests -v
```

汇总程序读取 `data/` 的真实会话，并逐项核对 `results/<session_id>/` 中既有汇总。缺少单会话分析时，先运行 `python analyze_results.py data/<session_id>_trials.csv`。原始试次与已有单会话分析不会被覆盖，新增汇总写入 `results/study/`，新增图片统一写入 `pics/`。

PDF 生成默认使用 Windows 中文字体；其他系统可通过 `--regular-font` 和 `--bold-font` 指定支持中文的 TrueType 字体文件。PDF 的数字和图表以 `docs/experiment_report.md` 为正文来源；更换数据后应同时重新核对正文。

## 解释范围

主要结论是方位差增大伴随辨别正确率提高，1°至 4°区间变化较明显。样本仅 4 人，每人每档只有 12 个不同试次；相同／不同判断还受应答标准与短时记忆影响。单调拟合属于事后补充分析，不能将生成的小数位数视为测量精度。原始自动阈值与补充阈值分别保存，具体区别见分析记录。
